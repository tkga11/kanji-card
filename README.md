# 漢字カード（書き取り練習）

あらかじめ登録した **245問** から、学年・文字数・苦手登録の条件に合った問題だけを出題する静的Webアプリです。

## 使い方

1. 出題学年（小学1〜6年、中学1〜3年）を選びます。
2. 「その学年まで」「その学年だけ」を選びます。
3. 1文字・2文字・3文字・4文字・1〜4文字ランダムから選びます。
4. カードをタップすると答えが表示され、再タップで問題に戻ります。
5. 前後の問題は「戻る」「次へ」で移動できます。前に戻っても同じ問題が再表示されます。
6. 「☆ 苦手に登録」した問題は端末内に保存されます。「苦手問題だけ」で復習できます。

問題の数は **登録済み問題の件数** です。選択条件に0問しかない場合は、そのまま0問と表示し別条件の問題を混ぜません。全問出題した後は次の周回に入ります。進捗は周回単位で集計します。

設定・苦手登録・出題履歴はブラウザの localStorage に保存されます。ブラウザのデータ削除や別端末では引き継がれません。

## GitHub Pagesに公開する方法（スマホだけでも可）

1. GitHub で **Public** の新規リポジトリ `kanji-card` を作成します（家計簿や掛け算カードのリポジトリとは分けます）。
2. ZIP をスマホで**展開**して、**このREADMEを含む8ファイル**をリポジトリのルートにアップロードし、`Commit changes` を押します。ZIP自体をアップロードするだけでは動作しません。
3. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` → `/(root)` → `Save`。
4. 公開先は `https://<GitHubユーザー名>.github.io/kanji-card/` です。アップロード後に数分かかる場合があります。

## 問題の追加・修正

- `questions.csv`：人が見たり修正したりするための一覧（UTF-8 BOM付き）です。
- `questions.js`：アプリが実際に読み込む登録済み問題集です。CSVだけを変えてもアプリには反映されません。
- 1問につき `id`, `grade`(1〜9), `answer`（漢字1〜4文字）, `reading`（ひらがな）, `before`（文の前半）, `after`（文の後半）を登録します。
- `grade` は答えに含まれる漢字のうち、最も遅く学習するものに合わせます。「その学年だけ」はこのgradeが一致するものを指します。
- 同音異義語の別解がないか、文脈・読み方を確認してから公開してください。複数の字の習得時期だけでなく、音訓の学校段階にも注意が必要です。
- 問題IDはユーザーの苦手履歴と紐づくため、既存のIDは変更しないでください。

## 教育上の注意

- 小学校の漢字の学年配当は、文部科学省の **学年別漢字配当表（平成29年告示）** を基準にしています。
- ただし、特定の漢字の**読み方を何年生の何学期に習うか**は全国共通で厳密に決められていません。この初期問題集の読み・語彙・文脈は編集用ドラフトを含み、実際の教科書に完全準拠したことを保証するものではありません。
- 中学校は漢字の**学年別配当が全国共通でありません**。中1・中2・中3のタグは、アプリ独自の参考分類であって、学校でその年に習うことを保証しません。
- 書き取り学習では、学年の途中でまだ未習の漢字が含まれる場合もあります。必要に応じて教科書に合わせて問題を選び直してください。

参考：
- 文部科学省【国語編】小学校学習指導要領（平成29年告示）解説: https://www.mext.go.jp/content/20220606-mxt_kyoiku02-100002607_002.pdf
- 文部科学省「音訓の小・中・高等学校段階別割り振り表」: https://www.mext.go.jp/a_menu/shotou/new-cs/1385768.htm

このプロジェクトは個人・家庭学習向けの非公式教材です。

## v1.1（2026年11月7日）前後文脈の学年別漢字表示

- 問題数、問題ID、対象の読み（reading）、正答（answer）を変更せず、245問すべてに `beforeParts` / `afterParts` を追加しました。
- 問題カードの前後文脈だけ、選択中の学年までに学べると確認した語句を漢字に変換します。
- 例えば「こうえんで【いぬ】とあそんだ。」は小1でそのまま、小2で「公園で【いぬ】とあそんだ。」、小3以上で「公園で【いぬ】と遊んだ。」となります。実際の画面では【】の代わりに太字で表示します。
- 設定が「その学年だけ」でも「その学年まで」でも、前後文脈の漢字表示は**選択した学年**を基準とします。
- `questions.csv` には表示を決める分割データがJSON形式で含まれます。CSVだけ変更してもアプリには反映されないため、実際の動作に使う `questions.js` と合わせて更新してください。
- `context-review.csv` は245問について、出題可能な各選択学年での表示を確認するための一覧です。GitHub Pages自体には不要です。
- `convert_context.py` はこの版の変換ルールを再生成する編集用スクリプトです。公開Webサイトには不要です。
- 読み方が学年別に全国一律に指定されないため、「該当学年で必ず既習」とは保証していません。曖昧な語・確認できない読みはひらがなのままにしています。教科書との全件照合は引き続き必要です。
- 以前のブラウザ履歴や苦手登録は、既存の問題IDと localStorage キーを維持することで引き継ぐ設計です（ブラウザデータが消去されていない場合）。
- `sw.js` のキャッシュ版を更新。別のGitHub Pagesアプリのキャッシュは消さないよう、`kanji-card-` で始まるキャッシュだけを削除するように修正しました。

## v1.2（2026年11月7日）表示漏れ修正と更新の安定化

- 出題「走っている【じどうしゃ】に気を付ける。」（小学4年生の表示例）に対応。「気」の漢字化が漏れていた問題 k3-033 を修正しました。
- オンライン時は最新のファイルを先に取得するネットワーク優先型のservice workerへ変更し、更新後に古い問題が表示される可能性を減らしました。
- 問題集スクリプトのURLにバージョン番号を付け、旧JSキャッシュとの混同を避けます。ヘッダーに v1.2 を表示するため更新を見分けられます。
- 問題ID・正答・読み・問題数は変更していません。端末のlocalStorageに保存された苦手登録や履歴も消しません。
- 初回のアップデート直後は既存のservice workerが残る場合があるため、ページを閉じて再度開くか、シークレットタブで確認してください。サイトデータの削除は苦手登録や履歴を失うため原則避けてください。
- 漢字の読みの教育学年については、引き続き採用教科書等による確認が必要です。
